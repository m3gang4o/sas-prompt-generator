# 🚀 SAS Creative Prompt Transfer Extension - Installation Guide

## Quick Install (5 minutes)

### Step 1: Download the Extension

1. Go to the [Releases page](https://github.com/m3gang4o/sas-prompt-generator/releases)
2. Download **`sas-prompt-transfer-extension.zip`**
3. Extract the ZIP file to a folder on your computer

### Step 2: Install in Chrome/Edge

1. Open Chrome or Edge browser
2. Go to `chrome://extensions/` (or `edge://extensions/`)
3. Turn ON **"Developer mode"** (toggle in top-right corner)
4. Click **"Load unpacked"**
5. Select the extracted extension folder
6. ✅ Extension installed!

### Step 3: Pin the Extension (Optional)

1. Click the puzzle piece icon 🧩 in your browser toolbar
2. Find "SAS Creative Prompt Transfer"
3. Click the pin icon 📌 to keep it visible

## How to Use

### Basic Workflow:

1. **Generate a prompt** in the [SAS Creative Prompt Generator](https://m3gang4o.github.io/sas-prompt-generator/)
2. **Click "Copy Prompt"** → Extension automatically stores it
3. **Open ChatGPT, Claude, Gemini, or Copilot**
4. **Notification appears** in top-right with instructions
5. **Click in chat box** → **Press Ctrl+V** (or Cmd+V on Mac)
6. **Upload your files** as reminded
7. **Press Enter** to submit

### Supported AI Platforms:

- ✅ ChatGPT (chatgpt.com)
- ✅ Claude (claude.ai)
- ✅ Google Gemini (gemini.google.com)
- ✅ Microsoft Copilot (copilot.microsoft.com)

## Troubleshooting

### Extension not storing prompts?
- Make sure you're using the web app at `127.0.0.1:3000` or the GitHub Pages URL
- Check that the extension is enabled in `chrome://extensions/`

### Notification not appearing on AI platforms?
- Refresh the AI platform page after copying a prompt
- Check that you have a prompt stored (click the extension icon to verify)

### Need to update the extension?
1. Download the latest version from Releases
2. Go to `chrome://extensions/`
3. Click "Remove" on the old version
4. Install the new version following Step 2 above
